🛠️ How to Install (Takes 30 seconds!)

Because this isn't on the Chrome Web Store yet, you have to install it manually. It's super easy:

  1. Extract the downloaded CoolStuffMachine.zip file into a normal folder.
  2. Open Google Chrome and type chrome://extensions/ into your URL bar and hit Enter.
  3. In the top-right corner, turn on the toggle switch for Developer mode.
  4. In the top-left corner, click the Load unpacked button.
  5. Select the folder you extracted in Step 1.
  6. Boom! Click the puzzle piece icon 🧩 in the top right of Chrome to pin it and start using it!
